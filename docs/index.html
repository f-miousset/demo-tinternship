Tinternship

Run Tinternship yourself

A team of AI agents that finds internships worth applying to, scores each one against what you want, and fills in your own CV and cover letter for it — every decision traced and audited. You triage what they find by swiping a deck.

Try the demo Source code Set it up

The demo calls no AI: every agent answer in it was written in advance, and your changes stay in your browser. This page is about the real thing — the same app, with its agents running on your own API key.

What you get

  • A search that knows what you want. An Interrogator interviews you once; an HR Expert researches how your kind of internship is actually hired, with sources; the Investigator searches with both.
  • Your documents, not generated ones. You upload the CV and letter you wrote, with [blanks] where something should change per application. A run fills only the blanks — your layout, fonts and wording survive, and the page stays one page, measured.
  • A Critic on every document. Each résumé, letter, interview brief and contact list is scored against a rubric; below the bar it is sent back for revision automatically.
  • Every link proved. A posting's link is fetched and checked before it is saved. No proof, no link.
  • Everything traced. Every agent, model call and tool call is logged with tokens, latency and cost on the Traces page.
  • A tracker that chases for you. Applications go quiet; after 14 days it drafts the follow-up e-mail, and when you reach an interview round it writes the brief.

Set it up — about ten minutes

You need Docker (Docker Desktop, or Docker Engine with Compose) and a Gemini API key. Nothing else.

  1. Get a Gemini API key

    Create one at aistudio.google.com/apikey. Alternatively a Google Cloud (Vertex AI) API key works — set GOOGLE_GENAI_USE_VERTEXAI=TRUE next to it, and Cloud credits pay for it.

  2. Get the code

    git clone https://github.com/f-miousset/demo-tinternship.git
cd demo-tinternship/selfhost

    The real app is in app/; selfhost/ holds the three-container setup that runs it.

  3. Put your key in .env

    cp ../app/.env.example .env

    Open .env and fill in the one required line:

    GOOGLE_API_KEY=your-key-here

    Every other setting is optional and explained in the file. The models, the quality threshold and the follow-up delay are changed later from the app's Settings page.

  4. Start it

    docker compose up -d --build

    The first build takes a few minutes (it installs a headless Chromium for checking job links). Then open http://localhost:8080.

    Port 8080 taken? PORT=8090 docker compose up -d.

  5. Set up your account, once

    The app opens on Account and keeps Jobs and Tracker closed until this is done:

    • Your four documents — your CV and your cover letter, in English and in French, as .docx. Leave [a_name_in_brackets] wherever something should be decided per application: [target_role], [list_of_relevant_courses], [cover_letter_opening_paragraph]… The name is the instruction. Want to try it first? selfhost/example-documents/ has a fictional candidate's four.
    • Two lists — your courses and your skills, each in both languages. The coursework and skills blanks are filled by picking from them, never by inventing.
    • The interview — answer the Interrogator's questions. When it has enough it writes your search brief, and the HR Expert researches a hiring playbook from it.

  6. Search, swipe, apply

    On Jobs, run the Investigator (or tell it what to focus on), swipe right on what you want, and press Generate on an application to get your filled-in CV and letter as .docx.

What it costs

Only your own API usage. A search run is typically a few cents, a résumé-and-letter run about the same; the Traces page shows the cost of every run as it happens. You can move the reasoning and critic tiers to local models with Ollama (Settings → models, and OLLAMA_BASE_URL=http://host.docker.internal:11434 in .env); grounded web search stays on Gemini.

Your data, and who can see it

  • Everything lives in selfhost/data/: three SQLite files and your documents. Back up that folder; delete it to start over. The app's Settings page also deletes by category.
  • The only outside services it talks to are the ones you configure: the Gemini API (or your local Ollama), and Adzuna if you add it.
  • There is no login. It is a single-user app and trusts whoever can reach it, so the compose file binds it to 127.0.0.1 — this machine only. To use it from your phone, put an authenticating reverse proxy in front of it; never just open the port.

Updating

git pull
docker compose up -d --build

Your data is untouched; the app migrates its own database on start.

Without Docker

For development: Python 3.14 with uv, and Node 24.

cd app
cp .env.example .env     # add GOOGLE_API_KEY
make install
make dev                 # API on :8000, UI on http://localhost:5173
make test                # the offline test suite — no key needed

How it is built

Google ADK agents on Gemini, FastAPI and SQLite behind a Vite/React PWA. Agents produce and Python persists: no agent saves its own work, and every promise the UI makes — counts, ordering, one page, the output language, the quality bar — is enforced in code rather than asked of a prompt. Read the agents in app/backend/src/tinternship_backend/agents/, the rubrics in agents/rubrics.py, and the prompts in agents/prompts.py.
